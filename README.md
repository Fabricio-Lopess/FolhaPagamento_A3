# 💰 Sistema de Folha de Pagamento

## 📌 Sobre o projeto

O **Sistema de Folha de Pagamento** é um projeto acadêmico desenvolvido em Java com o objetivo de automatizar o cadastro e o gerenciamento de colaboradores, além de realizar cálculos salariais e gerar informações relacionadas à folha de pagamento.

O sistema considera diferentes tipos de colaboradores, permitindo organizar seus dados e calcular a remuneração de acordo com cada modalidade.

## 🎯 Objetivos

- Facilitar o cadastro e a consulta de colaboradores.
- Permitir a edição e a exclusão de registros.
- Diferenciar os colaboradores de acordo com o tipo de remuneração.
- Realizar cálculos salariais.
- Gerar a folha de pagamento e um resumo dos valores calculados.
- Aplicar conceitos de programação e organização de código utilizando Java.

## 📂 Organização do projeto

O projeto possui quatro classes principais:

| Classe | Responsabilidade |
|---|---|
| `Main.java` | Ponto de entrada do programa e interação com o usuário. |
| `Colaboradores.java` | Representação dos colaboradores e seus dados. |
| `Vendas.java` | Representação das informações relacionadas às vendas. |
| `Producao.java` | Representação das informações relacionadas à produção. |

(Sujeito à futuras alterações durante o desenvolvimento do projeto)

## ▶️ Como executar

### Pré-requisitos

- JDK (Java Development Kit) instalado.
- Uma IDE compatível com Java, como IntelliJ IDEA, Eclipse ou NetBeans, ou um editor com suporte à linguagem.

### Passos

1. Clone este repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Entre na pasta do projeto:

   ```bash
   cd NOME_DO_REPOSITORIO
   ```

3. Abra o projeto na IDE de sua preferência.

4. Localize o arquivo `Main.java`.

5. Execute o método `main` para iniciar o sistema.

> **Observação:** substitua `URL_DO_REPOSITORIO` pelo endereço real do repositório no GitHub. A forma de compilação pelo terminal depende da estrutura de pastas e da declaração de pacotes do projeto.
